About this data

Real catalogued objects from the TraCSS Conjunction Assessment IV&V dataset (The Aerospace Corporation for the US Office of Space Commerce, CC0-1.0). Positions are at time of closest approach — this is not a live feed and nothing is propagated.
The 1e-10 Pc floor is inferred from the data, not documented. The Users Guide states only that Pc may be NULL when covariance is non-positive-definite.
This dataset validates screening geometry; it is not a Pc benchmark. The guide states directly that "direct comparison of Pc values requires the same method of Pc computation and is therefore not a key metric of this dataset."
Not for operational use. Public orbital data must never be used for operational collision avoidance.
Every chart is labelled population when it is drawn from all — ingested events, or sample when it is drawn from the —-event stratified sample. The sample deliberately over-represents rare high-probability events so they are visible at all — never read a dataset proportion off a sample chart.

Probability of collision

Alfano (2004), computed live by POST /pc. The same code reproduces the TraCSS prob column to a median ratio of 0.999994 over 20,000 events — which is a reproduction of their published method, not evidence that Pc is right about the world. No collision occurs anywhere in this dataset.

Covariance frame
This is the one input with no safe default. Two covariances published in different local frames cannot be summed until each is rotated to ECI, and choosing wrong raises no error anywhere — it just returns a different number. Switch this control and recompute: with the values loaded here the answer moves by a factor of about 6, and for in-track-dominated covariances in dissimilar orbital planes it can move by six orders of magnitude.

Kelvins series
The agent is a corrector on an alert queue: it is invoked only when the latest visible risk is at or above −7.0. Below that the event falls through to the baseline with no call made. That is the protocol Phase 6 pre-registered and Phase 7 scored, unchanged.
Kelvins events are anonymised and time-shifted. They carry no TCA and no catalogue identity, so nothing here can be joined to a real object — and nothing here is a live warning.
